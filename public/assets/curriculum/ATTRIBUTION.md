| `ml` | Living root bridge, Nohkalikai, Jadoh, Khasi attire, Shad Suk Mynsiem |
| `mn` | Loktak, Sangai, Yaoshang, Kangla |
| `nl` | Dzukou valley, Naga shawl, Hornbill / folk dance |
| `mz` | Chapchar Kut / Cheraw, Mizo dress, Aizawl parks |
| `tr` | Ujjayanta, Neermahal, Chaturdasha (Kharchi), Rignai |
| `ar` | Tawang Monastery, Apatani / Ziro, Urgelling |
